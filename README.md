# SGS Fund website

Static SGS Fund website, hosted with GitHub Pages at
[sgsfund.planetariumlabs.com](https://sgsfund.planetariumlabs.com).

## Publishing

GitHub Pages publishes the `main` branch from the repository root. Pushing to
`main` updates the site automatically.

The custom domain is declared in `CNAME`. Its DNS record is:

| Host | Type | Value |
| --- | --- | --- |
| `sgsfund` | `CNAME` | `planetarium.github.io` |

DNS is managed in the `planetariumlabs.com` Route 53 hosted zone.
